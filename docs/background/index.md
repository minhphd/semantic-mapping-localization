# Background Knowledge

If you have taken intro CS and data structures but not yet studied robotics, machine learning, or computer vision, then this section is for you. Each page covers one area of background knowledge you need before the rest of the docs will feel natural. None of it assumes prior robotics experience — just familiarity with Python and some vague memory of high school math.

Read them in order, or jump to whichever feels most unfamiliar.

| Page | What you'll learn |
|------|-------------------|
| [Linear Algebra in Python](linear_algebra.md) | Vectors, matrices, transforms, and how to use them in NumPy |
| [Intro to Machine Learning](machine_learning.md) | Neural nets, MLPs, embeddings, training vs inference |
| [Intro to Computer Vision](computer_vision.md) | Detection, segmentation, vision-language models, and the full perception pipeline |
| [Intro to NLP](nlp.md) | LLMs, transformers, cosine similarity, vector search, and VLAD |
| [Robot Hardware](robot_hardware.md) | Sensors, depth cameras, intrinsics, poses, and the Spot platform |
| [ROS2 & Spot Telemetry](ros2.md) | ROS2 concepts and how this repo publishes live Spot data to ROS2 topics |
| [Open Problems in Robotics](open_problems.md) | Why localization and mapping are hard, and how this project addresses both |
