# Getting Started

Welcome to **Spot Semantic Mapping**. Follow these three steps to go from installation to your first scene graph.

---

## Before You Begin

| Requirement | Minimum | Recommended |
|------------|---------|-------------|
| GPU (NVIDIA) | GTX 1080 — 8 GB VRAM | RTX 3090 / A100 |
| RAM | 16 GB | 32 GB |
| Disk | 20 GB | 50 GB (with model weights) |
| OS | Ubuntu 20.04 | Ubuntu 22.04 |
| Docker | 24.x | latest |
| CUDA | 11.8 | 12.8 |

!!! tip "New to Docker or Conda?"
    See the [Prerequisites](../prerequisites/index.md) section for setup guides before continuing.

---

## Steps

<div class="grid cards" markdown>

-   **1 · Installation**

    Clone the repo, build the Docker image or create a Conda environment, and verify your GPU is visible.

    [→ Installation](installation.md)

-   **2 · Configuration**

    Set model checkpoint paths, camera parameters, and API keys in `main_config.yml`.

    [→ Configuration](configuration.md)

-   **3 · Quick Start**

    Build your first scene graph from a sample iPhone or Spot recording using the CLI or Python API.

    [→ Quick Start](quickstart.md)

</div>
